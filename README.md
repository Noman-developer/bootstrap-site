# bootstrap-site

A simple one page website I made with Bootstrap while learning.

## What it is

This is a small practice project. It is a one page site with a navbar, a hero section, an about section, a services section, and a footer. The navbar links jump to each section on the page.

## Features

- Dark navbar with Home, About, and Services links
- Blue hero section with a "Learn More" button that scrolls to the About section
- About section with a short text
- Services section with three cards: Web Design, Development, and Support
- Dark footer with a copyright line
- Works on mobile too, because it uses Bootstrap's grid
- Bootstrap files are saved in this repo, so the page works even without internet

## Tech stack

- HTML
- Bootstrap 5.3.2 (local copy in the `css` and `js` folders)

## How to view

Just open `index.html` in any web browser. No setup or server needed.
